# Camera Rental Management System #

# About the Project

The Camera Rental Management System is a desktop application developed using Python and Tkinter.

The purpose of this project is to simplify the management of camera rentals by providing an interface to manage camera inventory, customers, rental transactions and equipment returns.

This is a personal portfolio project developed to improve my programming and software development skills.

# Features

- Camera inventory with pre-registered cameras.
- Customer registration.
- Camera rental management.
- Automatic rental price calculation.
- Rental history.
- Camera return management.
- Dashboard with inventory and rental statistics.

# Technologies Used

- Python 3
- Tkinter
- SQLite (planned for a future version)

      bash

3. Run the application:
